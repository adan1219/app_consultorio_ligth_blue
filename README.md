# app_consultorio_light_blue

Aplicación local para gestión de consultorio dental.

## Tecnologías del proyecto

| Área | Tecnología |
|---|---|
| Lenguaje | Python 3 |
| Interfaz gráfica | Tkinter + tkcalendar |
| Procesamiento de datos | pandas + numpy |
| Persistencia | Excel (.xlsx) mediante openpyxl |
| Gráficas | matplotlib |
| Generación de PDF | **reportlab** |

## Nota sobre PDFs

La generación de PDF en el proyecto se implementa con `reportlab` (módulos `reportlab.pdfgen`, `reportlab.platypus` y utilidades de `reportlab.lib`).
